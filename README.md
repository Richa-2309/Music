# 🎵 Music System

A modern and responsive **Music System Website** built using only **HTML, CSS, and JavaScript**.

The project provides a clean music-player interface with song search, playlist navigation, play/pause controls, next/previous buttons, progress tracking, and volume control.

## 🚀 Features

* 🎵 Modern music player UI
* ▶️ Play and Pause functionality
* ⏮️ Previous song
* ⏭️ Next song
* 🔍 Search songs
* ⏱️ Music progress bar
* 🔊 Volume control
* 🎧 Current song information
* 📀 Popular songs section
* 📋 Playlist sidebar
* 📱 Responsive design for mobile and desktop
* 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Music player functionality and interactions

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/music-system.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! No installation or backend server is required.

## 🎧 How It Works

The application uses JavaScript to manage the music player state.

### Play Song

Clicking the play button loads the selected song information into the music player.
